Mac 37종은 파일 읽기와 지문 확인 기록이다. 초기 목록 본문과 현재 사본의 버전 일치, 현재 에이전트 활성화, 모든 작업의 실행 성공을 뜻하지 않는다. Windows는 대조하지 않아 미확인이다. 과거 적용 검수는 네 스킬의 특정 lete-on 작업 범위로만 표시했다. 체크리스트 선택은 브라우저 메모이며 검증 상태를 변경하지 않는다.

source-to-memory 두 원본은 유지한다. 비교 창에서 각 사본과 사용자·프로젝트 규칙에 따른 선택 순서를 제공한다. 전역 기준 사본을 임의 지정하지 않는다.
